# License scope map

- Root [LICENSE](../LICENSE) is the canonical `AGPL-3.0-only` license for the
  current first-party source tree.
- [MIT.txt](MIT.txt) preserves the outbound license used by repository
  snapshots through and including full commit
  `8f317df7ac5bb687ac8fbbfcd23abc1385be396d`.

The presence of both texts does **not** offer the current source as
`AGPL-3.0-only OR MIT`. Historical code received under MIT keeps those rights;
the transition release and later snapshots use the policy in
[LICENSE_POLICY.md](../LICENSE_POLICY.md).
